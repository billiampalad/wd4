Galeri Varian Tampilan (Styles)

Pilih gaya tampilan visual yang sesuai dengan kebutuhan layout halaman.

1. Default (Bordered) variant="default"

Border elegan dengan soft focus glow ring.

2. Filled (Surface2 Tint) variant="filled"

Latar belakang lembut yang menyatu dengan kartu dashboard.

3. Pill (Full Rounded) variant="pill"

Sudut membulat penuh, ideal untuk topbar / hero section.

4. Glassmorphism variant="glass"

Efek kaca transparan (backdrop-filter blur).

5. Search + Submit Button button="true"

Dilengkapi tombol aksi submit langsung.

6. Loading Spinner State .is-loading

Indikator memuat saat mencari data asinkron / AJAX.

Varian Ukuran (Sizes)

Tersedia dalam ukuran Small (sm), Medium (md - standar), dan Large (lg).

Small (size="sm" - 32px height)
Medium (size="md" - 40px height - Default)
Large (size="lg" - 48px height - Hero Search)
